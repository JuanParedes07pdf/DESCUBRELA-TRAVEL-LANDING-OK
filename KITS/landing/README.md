# UI Kit — Landing Page

## Descúbrela Travel Landing Page

Full interactive landing page prototype based on the PRD "Tu Primer Viaje" and the Zander-style brief.

## Sections
1. **Nav** — Fixed navbar, transparent→navy on scroll, logo + nav links + WhatsApp CTA
2. **Hero** — Full-viewport hero, logo feature element + polaroid social proof
3. **Problem** — Pain agitation + comparison table (Agencia grande vs. Descúbrela)
4. **Services** — 4 pillars card grid with hover states
5. **Destinations** — Tabbed destination hub (Europa, EE.UU., Asia, Caribe, Colegios) + video placeholder
6. **Process** — 4-step process with animated cards on navy background
7. **Footer** — Full footer with social links, partner logos (Amadeus, Sabre), WhatsApp
